- **Directory review fix.** 3.12.1 failed the community directory's automated source review with "Source review dependency installation failed": the repository could only be installed with `npm install --legacy-peer-deps` because the unused `eslint-plugin-obsidian` (an unrelated react-obsidian lint plugin that pins ESLint 8) conflicted with ESLint 9. The package is removed, `@types/node` follows Vite's supported range, and `npm install` / `npm ci` now resolve without flags. CI and the release workflow were updated accordingly.
