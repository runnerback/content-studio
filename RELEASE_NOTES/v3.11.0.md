title: Community release preparation
---
Prepared for submission to the Obsidian community plugin directory.

- Plugin id renamed to `note-content-studio` (the former id was already taken in the directory); display name is now **Note Content Studio**. Re-enable the plugin once after updating.
- Toolbar buttons switch visibility via CSS class instead of inline styles; removed the last `!important` rules.
- Neutral default rednote header/footer texts; upstream author defaults and machine paths removed.
- LICENSE now retains the copyright notices of obsidian-wechat-converter and note-to-red; README gains network/privacy disclosure and acknowledgements.
- The command to open the panel is now `打开预览面板` (command names no longer include the plugin name).
