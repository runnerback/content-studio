---
title: License service moved to api.runfast.ren
---
- **License service domain.** The metered Xiaohongshu / X publishing uses the author's license service, which moved from `api.runfast.xyz/license` to `api.runfast.ren/license` (the server was relocated on 2026-11-04 and the old domain stops working when the old server is shut down). Without this update the plan list on the "Xiaohongshu / X (browser extension)" settings page fails to load and redeeming an Afdian order number returns a network error.
- **Update the Crosspost extension to 3.1.7 too.** Quota metering is requested by the browser extension; older versions still point at the old domain and refuse to publish with "cannot reach the license service".
- License keys and the daily count live on the server and are unchanged. No settings migration. WeChat articles, image cards, Feishu sync and AI layout never contact this service and are not affected.
- README network-use disclosure and the quota guide now name the new domain.
