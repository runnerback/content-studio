---
title: Desktop-only, 1.3 MB bundle, English UI for settings, publishing dashboard
---
- **Bundle size 3.8 MB → 1.3 MB.** Math now renders with Obsidian's built-in MathJax (CHTML) instead of a bundled SVG engine; formulas are rasterized to PNG only when copying to WeChat or saving a draft through the API. The built-in Xiaohongshu card backgrounds were re-encoded to WebP.
- **Desktop only** (`isDesktopOnly: true`). The local WebSocket bridge and Feishu image handling need desktop APIs; the mobile app previously crashed on those paths.
- **Honest status for the companion extension.** Until the Crosspost browser extension is released, the settings page and the publish modal say so instead of listing build-and-sideload steps. Cards delivered to the extension are recorded as `publish_status: pending` / `publish_pending` and the notice says "awaiting confirmation", because the extension only acknowledges receipt.
- **Settings consolidated.** Phone frame and image watermark moved into the preview panel's advanced options and apply immediately; dead settings (Feishu smart update / double-link / debug logging, legacy single-account fields) removed; the extension page is named "Xiaohongshu / X (browser extension)".
- **Settings, commands and the Xiaohongshu card settings follow Obsidian's language**: Chinese (Simplified or Traditional) → Simplified Chinese, anything else → English. Dictionaries live in `services/locales/`.
- **Publishing dashboard** (`Open publishing dashboard` command, toolbar button): targets from frontmatter `platform` (arrays allowed for multi-platform posts), published / awaiting / not-yet columns, filters by platform, status and keyword.
- **AI layout cost visibility**: token usage per run and a per-device total in settings, optional price per million tokens for a cost estimate; cached layouts generated by an older skill version are flagged as outdated.
- Code structure: the entry file and the AI layout service were split into focused modules; docs (CLAUDE.md, CONTRIBUTING, RELEASING, guides) refreshed and a user-facing CHANGELOG added.
