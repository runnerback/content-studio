---
title: Release workflow publishes only after assets are attached
---
- No plugin code changes since 3.11.10.
- The release workflow now creates the GitHub Release as a draft, verifies `main.js` / `manifest.json` / `styles.css` are attached, and only then publishes it. The Obsidian community directory reads release assets the moment a release is published; 3.11.10 was reviewed during the upload window and wrongly reported as missing `main.js` and `manifest.json`.
