---
title: Community release preparation
---
Prepared for submission to the Obsidian community plugin directory.

- Plugin id renamed to `note-content-studio` (the former id was already taken in the directory); display name is now **Note Content Studio**. Re-enable the plugin once after updating.
- Toolbar buttons switch visibility via CSS class instead of inline styles (initial state and mode switch share `applyToolbarMode`); removed the last `!important` rules.
- Neutral default rednote header/footer texts; upstream author defaults and machine paths removed.
- LICENSE now retains the copyright notices of obsidian-wechat-converter and note-to-red; README gains network/privacy disclosure and acknowledgements.
- The command to open the panel is now `打开预览面板` (command names no longer include the plugin name).
- Fix: rednote toolbar buttons (style settings / download) disappeared in 小红书 mode after 3.11.0; initial state and mode switch now share `applyToolbarMode` (regression test added).
- Build: `check:build-artifacts` no longer reports untracked artifacts generated for the first time as drift, so the release workflow can pass on a fresh checkout.
- Rednote header/footer defaults are now generic placeholders (你的昵称 / @yourid / 记录生活 · 分享思考 / 欢迎关注 · 点赞收藏). Saved settings still holding the upstream author's texts are migrated once on load.
