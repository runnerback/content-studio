## 设置面板速览

打开：Obsidian 设置 → 第三方插件 → Content Studio（或转换器面板右上角齿轮）。

> v3.10.0 起（要求 Obsidian ≥ 1.13.0）设置面板改用 Obsidian 声明式设置：公众号相关设置直接列在面板顶层（可用 Obsidian 设置搜索直达）；**飞书 / 其他平台 / 小红书** 是三个子页面，点击对应行进入，左上角返回。

面板顶层从上到下的主要区块：

1. **预览模式 / 图片水印** —— 手机框、水印头像（上传 / 清除 / 备用 URL）
2. **微信公众号账号 → 账号列表** —— 默认账号下拉；列表行点击编辑（含测试连接），右上角「+」添加，行尾删除（多账号）
3. **AI Provider → AI Provider 列表** —— AI 能力的共享凭证（当前 DeepSeek），详见 [AI Provider 设置](./ai-provider.md)
4. **AI 编排** —— 开关、模型质量、默认布局 / 颜色、请求超时、清空缓存
5. **标题 AI 润色** —— 开关、模型质量
6. **高级设置 → API 代理地址 / 测试代理** —— 见 [API 代理设置](./api-proxy.md)
7. 子页面：**飞书**、**其他平台**、**小红书**

多平台发布（小红书 / 知乎 / 头条 等）走「其他平台」子页面 + 配套浏览器扩展「多栖 Crosspost」，见 [小红书图文发布](./rednote-publishing.md)。
