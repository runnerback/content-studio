## 设置面板速览

打开：Obsidian 设置 → 第三方插件 → Note Content Studio（或转换器面板右上角齿轮）。界面语言跟随 Obsidian：中文（简体、繁体）显示简体中文，其它语言显示英文（v3.12.0 起）。

> v3.11.4 起（要求 Obsidian ≥ 1.13.0）设置面板按 **样式 / 分发 / AI** 三组排布，每组内是子页面，点击进入、左上角返回；所有项都能在 Obsidian 设置搜索里直达。
> v3.12.0 起「公众号排版」页取消：手机仿真框、图片水印（头像上传 / 清除 / 备用 URL）挪到**预览面板 → 样式设置 → 高级选项**，改动即时生效，不再需要重开面板。

| 组 | 子页面 | 内容 |
|---|---|---|
| **样式设置** | 小红书图卡 | 图卡用户信息（头像 / 昵称 / ID / 时间）、标题分割级别、页眉页脚开关、主题与字体管理（X 图卡同款） |
| | （一级开关）按文档属性自动切换预览平台 | 切换文档时按 frontmatter `platform`（wechat / rednote / x，可写数组一稿多发）切预览平台，默认开 |
| **分发设置** | 微信公众号 | 默认账号、账号列表（点击编辑 / 测试连接，右上角「+」添加，行尾删除）、API 代理地址与测试代理（见 [API 代理设置](./api-proxy.md)） |
| | 飞书 | 飞书自建应用、目标文件夹、OpenAPI 调用统计 |
| | 小红书 / X（浏览器扩展） | 浏览器扩展「多栖 Crosspost」连接（扩展尚未公开发行，页面会如实标注）、许可密钥 / 爱发电兑换 / 今日额度（见 [额度与许可](./quota-and-license.md)、[小红书图文发布](./rednote-publishing.md)） |
| **AI 设置** | AI Provider 与编排 | AI Provider 列表与默认 Provider、AI 编排（开关 / 模型质量 / 默认布局与颜色 / 超时 / 清空缓存）、本机累计用量与单价估算、标题 AI 润色（见 [AI Provider 设置](./ai-provider.md)） |

## 预览面板里的样式设置（不在插件设置页）

预览面板右上角「公众号排版样式设置」悬浮层：主题 / 主题色 / 字体 / 字号 / 两侧留白；「高级选项」含引用样式、标题主题色、标点标准化、Mac 风格代码块、代码行号、**手机仿真框、图片水印**、图片说明文字。所有项改动即时生效。

## 分发看板（v3.12.0）

命令面板「打开分发看板」或预览面板顶栏的看板按钮：按笔记列出目标平台（frontmatter `platform`）、已发布（`platform_<name>: 1`）、待确认（`publish_pending`，经扩展投递但尚未确认写入）、未发布与最近时间，可按平台 / 状态 / 关键词筛选，点标题打开笔记。
