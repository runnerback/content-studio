# 小红书 / X 发布额度与许可

> **适用插件版本**：v3.11.3 ｜ **最后更新**：2026-09-15 ｜ 编码：UTF-8

## 1. 计量规则

小红书 / X 的草稿发布经配套浏览器扩展 Crosspost 完成。每次成功投递一个平台计 1 次，按北京时间自然日重置：

| 档位 | 每日次数 | 获取方式 |
|---|---|---|
| Free | 3 | 默认，无需注册 |
| Pro | 30 | 付费许可密钥 |
| Max | 不限 | 付费许可密钥 |

- 发布失败（扩展返回失败）会自动退回这一次。
- Free 档按浏览器扩展的设备 ID 计数；Pro / Max 按密钥计数，同一密钥在多台电脑上共享额度。
- 图卡预览、PNG / ZIP 导出、复制文案不计量，也不需要扩展。

## 2. 购买与填写密钥

1. 国内：在爱发电主页 https://afdian.com/a/note_content_studio 购买对应方案（¥19 Pro / ¥39 Max，按月）→ 复制**订单号** → Obsidian 设置 → Content Studio → 其他平台 → 「用爱发电订单号兑换密钥」→ 兑换。密钥会自动填入「许可密钥」。
2. 海外：Lemon Squeezy 渠道开通后，在其结账页购买 → 邮件里的 License Key 直接粘贴到「许可密钥」。
3. 密钥到期后自动降为 Free 档，设置页与发布弹窗会提示「许可密钥已过期」。续费后无需改密钥（爱发电续费延长同一密钥；Lemon Squeezy 订阅自动续期）。

购买入口在设置页「额度」一行的「购买 Pro / Max」链接（由许可服务下发，随时可能调整）。

## 3. 在哪里看额度

- 设置 → 分发设置 → 其他平台，「许可密钥」下方的「额度」提示：第一行是当前方案、今日剩余、重置时间与到期日（如 `当前方案 Pro · 今日剩余 28/30 次（9/16 00:00 重置） · 到期 2026-10-15`，需扩展在线）；第二行是档位说明 `Free 每日 3 次 ｜ Pro 每日 30 次 ｜ Max 不限次`（读自许可服务）；后面跟购买 / 续费链接。
- 发布弹窗顶部提示行同样显示今日剩余；Pro / Max 会高亮。
- 额度用尽时发布会被拒绝并弹出「今日发布额度已用完」，可直接点「升级 Pro / Max」或「填写许可密钥」。

## 4. 隐私与网络

计量请求由浏览器扩展发往 `api.runfast.xyz/license`，只包含：匿名设备 ID、许可密钥（如有）、平台名。不发送笔记标题、正文或图片。插件本身只在兑换爱发电订单号时访问该服务。

## 5. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 提示「无法连接许可服务」 | 扩展访问不到 `api.runfast.xyz`，检查浏览器网络 / 代理；许可服务不可达时不会放行发布 |
| 设置页额度显示「连接浏览器插件后显示」 | 扩展未连上本机桥接，先点「测试连接」 |
| 兑换提示「未找到该订单」 | 爱发电回调通常 1 分钟内到账；确认订单号完整、已支付 |
| 兑换提示「方案未配置档位」 | 作者侧尚未把该方案映射到档位，联系作者处理 |
| 填了密钥仍按 Free 计量 | 看提示是「已过期」「无效」还是「已停用」；无效多为复制时带了空格或少字符 |
